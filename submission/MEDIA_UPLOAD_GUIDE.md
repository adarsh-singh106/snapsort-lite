# DEV media upload guide

The files in `submission/assets/` are local evidence, not public URLs. DEV posts cannot display a contributor's Windows filesystem paths.

1. Open the DEV editor for the draft.
2. Upload `cover.png` as the article cover image.
3. Upload `before-after.png` below the `### Demo` heading and keep the caption that says the files are fictional and generated locally.
4. Upload `architecture.png` in `### How I Built It`.
5. Upload `terminal-demo.gif` if it is generated locally, or replace it with a real screen recording URL.
6. Replace each `[DEV IMAGE URL AFTER UPLOAD]` marker in `DEV_SUBMISSION.md` with the URL returned by the DEV editor.
7. Do not upload or expose screenshots from a real personal screenshot directory.

No hosted demo video was created in this environment. A real screen recording can be made with OBS or Xbox Game Bar while running the commands in `demo/DEMO.md`; do not describe the local GIF or still images as a video.
